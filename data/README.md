# Data (not committed)

Download **annotations** from the official RailEye3D GitHub repository:
https://github.com/raileye3d/raileye3d_dataset

The **images are not included** with the annotations. Request image sequences from the dataset authors using the instructions in their README. Follow their non-commercial licence and do not re-host the images.

Expected files:

```text
data/
├── annotations/raileye3d_dataset/anno/unified/
│   ├── bboxes/red-00-00-front-left/00000.csv
│   └── params/red-00-00-front-left/00000.csv
└── images/
    └── red-00-00-front-left/00000.jpg
```

Actual image file extension may be jpg/jpeg/png/webp. Paths are examples, not bundled data.
